Экосистема и инструменты

Современный фронтенд не ограничивается одним лишь фреймворком. Вот обязательный стек сборки и управления проектом.

Node.js & npm

Среда выполнения JavaScript на сервере и крупнейший менеджер пакетов для управления зависимостями проекта.

Vite

Современный и сверхбыстрый сборщик проектов, пришедший на смену устаревающему Webpack.

TypeScript

Строго типизированное подмножество JS, предотвращающее ошибки ещё на этапе написания кода.

ESLint & Prettier

Инструменты для проверки качества кода и его автоматического форматирования по стандартам.

Менеджеры пакетов

  • npm — стандарт по умолчанию
  • yarn — альтернатива от Meta
  • pnpm — экономит место на диске

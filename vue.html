Vue.js

Прогрессивный JavaScript-фреймворк для создания пользовательских интерфейсов, созданный Эваном Ю.

Главные особенности

  • Прогрессивная архитектура: Можно использовать как простую скриптовую библиотеку или как полноценный фреймворк.
  • Single File Components (.vue): Шаблон, логика и стили компонента хранятся в одном файле.
  • Реактивность: Автоматическое обновление UI при изменении данных состояния.

Система директив

Vue использует специальный синтаксис шаблонов в HTML:

v-if — условное форматирование элементов
v-for — рендеринг списков
v-model — двустороннее связывание данных в формах
